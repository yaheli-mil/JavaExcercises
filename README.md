# Java Exercises

A personal practice repository with Java implementations of core data-structure and algorithm exercises.

## Repository contents

- `/tmp/workspace/yaheli-mil/JavaExcercises/Node.java` – Generic linked-list node implementation.
- `/tmp/workspace/yaheli-mil/JavaExcercises/Queue.java` – Generic queue implemented with linked nodes.
- `/tmp/workspace/yaheli-mil/JavaExcercises/BinTreeNode.java` – Generic binary-tree node class.
- `/tmp/workspace/yaheli-mil/JavaExcercises/Game.java` – Simple model class (`name`, `price`).
- `/tmp/workspace/yaheli-mil/JavaExcercises/Store.java` – Store-related linked-list exercises.
- `/tmp/workspace/yaheli-mil/JavaExcercises/Room.java` – Queue-based room/user exercise code.
- `/tmp/workspace/yaheli-mil/JavaExcercises/QueueExercises.java` – Main collection of queue/recursion/tree practice methods and examples.

## Goals

- Practice Java syntax and OOP basics.
- Strengthen understanding of linked structures and queues.
- Solve algorithmic problems using recursion and helper data structures.

## How to run

This repository does not currently include a Maven or Gradle project setup.
Use the JDK command-line tools directly from the repository root:

```bash
cd /tmp/workspace/yaheli-mil/JavaExcercises
javac *.java
java QueueExercises
```
